# Code of conduct

KnowTier contributors and users are expected to communicate with respect, patience, and professional
care. Harassment, discrimination, threats, deliberate disclosure of private information, and sustained
disruption are not acceptable in project spaces.

Assume good intent while discussing technical decisions, focus criticism on the work, and protect
learner data and credentials in every report. Maintainers may edit or remove harmful content and may
temporarily or permanently restrict participation when necessary to protect the community.

Report conduct concerns privately through the repository maintainer's GitHub profile rather than in a
public issue. Good-faith reports will be handled as confidentially as practical. This project adopts
these expectations for repository issues, pull requests, reviews, discussions, and related project
communication.
