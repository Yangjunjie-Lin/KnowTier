# Support

## User help

Start with the [desktop guide](docs/DESKTOP.md), especially its installation, model-provider, data,
and troubleshooting sections. Verify that you are using the
[latest release](https://github.com/Yangjunjie-Lin/KnowTier/releases/latest) and that its checksum
matches `SHA256SUMS.txt`.

For reproducible non-security defects, open a GitHub issue with the application version, operating
system, exact steps, expected and observed behavior, and sanitized logs. Do not attach API keys,
documents, databases, learner names, prompts, full provider responses, or other private data.

Use [SECURITY.md](SECURITY.md) for vulnerabilities. General usage questions and enhancement requests
may use GitHub Issues. Support is community/maintainer best effort; the MIT-licensed project does not
include a guaranteed service-level agreement.
